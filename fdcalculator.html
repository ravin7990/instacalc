How this FD interest calculator works

This FD maturity amount calculator estimates your fixed deposit returns based on deposit amount, annual interest rate, tenure, payout mode, and compounding frequency. In cumulative mode, interest is reinvested. In non-cumulative mode, interest is treated as periodic payout.


Formula reference (cumulative): FV = P * (1 + r/n)^(n*t). For non-cumulative view: FV = P + (P * r * t).


This fixed deposit return calculator supports common search needs like quarterly interest estimation, cumulative and non-cumulative FD comparison, and principal-plus-interest planning for India users.

How to calculate FD maturity amount?

Enter principal amount, FD interest rate, tenure, and compounding frequency. The calculator then applies the maturity formula to estimate total value and interest earned.

Can I use this as a monthly interest FD calculator?

Yes. Select non-cumulative payout mode to estimate periodic interest payout behavior and compare it with cumulative compounding.

How does the senior citizen FD option work?

Enable senior citizen mode to add a rate boost to the selected FD interest rate. The calculator updates maturity, interest, and target-principal estimates automatically.

Is FD interest taxable and can this calculator estimate post-tax return?

FD interest is taxable as per your slab. This page applies your selected tax rate on total interest and shows an estimated post-tax maturity amount.
